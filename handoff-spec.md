# HANDOFF Spec v2

Machine-readable conventions for `HANDOFF.md` generated by handoff-md.

## Header

- Title: `# HANDOFF — {projectName}`
- Metadata line must include `handoff-spec: 2`

## Required sections

| Section | Description |
|---------|-------------|
| `## Stack` | Language, framework, tooling |
| `## Right now` | Briefing bullets (synthesized from git/state) |

## Optional sections

| Section | Description |
|---------|-------------|
| `## Notes` | Human overlay from `.handoff.overlay.md` |
| `## Scripts` | package.json scripts |
| `## Workspace` | Monorepo layout |
| `## CI` | GitHub Actions workflows |
| `## PR context` | GitHub PR/issues (when `gh` available) |
| `## Structure` | Directory tree |
| `## Conventions` | Naming + AI config excerpts |
| `## Recent Activity` | Git commits |
| `## Current State` | Uncommitted changes, branches |
| `## Known Issues` | TODO/FIXME/HACK |
| `## Environment` | Env var names from examples |
| `## Warnings` | Analyzer warnings |

## Token budgets

| Format | Total cap (approx) |
|--------|-------------------|
| compact | 1500 |
| standard | 3000 |
| full | 5000 |

Under budget pressure, low-priority sections are dropped before high-priority ones (see `SECTION_DROP_ORDER` in assembler).

## JSON output (`--json`)

```json
{
  "markdown": "string",
  "tokenEstimate": "number",
  "warnings": ["string"],
  "meta": {
    "projectName": "string",
    "outputPath": "string",
    "format": "compact|standard|full",
    "cacheHits": ["string"]
  }
}
```

## Validation

- `handoff-md validate` — required sections exist
- `handoff-md check` — CI quality gate (tokens, age, spec version)
